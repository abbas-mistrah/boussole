# Boussole

**AI transformation operating system** — cockpit that turns a use-case portfolio into board-ready decisions: selection, adoption, governance, proof.

> Not a dashboard toy. The system that keeps AI work decidable for a COMEX.

## What it is

| Layer | Job |
|:------|:----|
| **Selection** | What to fund, what to kill, who owns the case |
| **Adoption** | Operating model, cadence, owners, enablement |
| **Governance** | Risks, go–no-go, compliance path |
| **Proof** | KPI / IBC, FinOps signal, COMEX narrative |

Built and run in a multi-department AI transformation mandate.

---

## Architecture

```text
                    ┌─────────────────────────┐
                    │     COMEX / sponsors     │
                    └────────────┬────────────┘
                                 │ mandate / KPI
                    ┌────────────▼────────────┐
                    │        BOUSSOLE          │
                    │  portfolio · owners ·    │
                    │  risks · proof · cadence │
                    └─────┬───────────┬───────┘
           ┌──────────────┘           └──────────────┐
           ▼                                         ▼
   Use-case pipeline                          Enablement
   (select → live)                            & adoption
           │
           ▼
   Delivery surfaces (e.g. LeBon AI)
```

**Principle:** the model is the last floor. Selection and adoption sit above it.
